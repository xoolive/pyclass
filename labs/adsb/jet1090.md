Use [`jet1090`](https://mode-s.org/jet1090/) to capture ADS-B data. It decodes Mode S/ADS-B messages from an RTL-SDR USB dongle, displays nearby aircraft, and writes the received messages directly to a JSON Lines file.

## Install `jet1090`

Follow the [jet1090 installation instructions](https://mode-s.org/jet1090/install/). The recommended commands are:

| Operating system      | Command |
| --------------------- | ------- |
| Linux                 | `curl --proto '=https' --tlsv1.2 -LsSf https://github.com/xoolive/jet1090/releases/latest/download/jet1090-installer.sh \| sh` |
| macOS                 | `brew install xoolive/homebrew/jet1090` |
| Windows (PowerShell)  | `powershell -ExecutionPolicy ByPass -c "irm https://github.com/xoolive/jet1090/releases/latest/download/jet1090-installer.ps1 \| iex"` |

<div class="alert alert-warning">
<b>Windows:</b> before using the RTL-SDR dongle, install its driver with <a href="https://zadig.akeo.ie/">Zadig</a>. This requires administrator rights. Plug in the dongle, select it in Zadig, then install the <code>WinUSB</code> driver.
</div>

## Check that reception works

Plug in the antenna and run the following command. The `--verbose` option prints decoded JSON messages in the terminal; stop it with <kbd>Ctrl</kbd>+<kbd>C</kbd> once messages arrive.

```sh
jet1090 --verbose rtlsdr:///@LFPO
```

`LFPO` is the reference location for Paris-Orly. A reference location also lets jet1090 decode messages sent by aircraft on the ground. Replace it with the ICAO code for your nearest airport, or with latitude and longitude separated by a comma.

## Record and display data

Use this command during the recording:

```sh
jet1090 -o output.jsonl --interactive rtlsdr:///@LFPO
```

- `--interactive` displays a table of visible aircraft, like the old interactive mode of `dump1090`;
- `-o output.jsonl` saves every decoded message in `output.jsonl` at the same time;
- `rtlsdr:///@LFPO` selects the RTL-SDR dongle and provides the reference location.

`output.jsonl` uses the [JSON Lines](https://jsonlines.org/) format: each line contains one decoded message. You can analyse it later with Python, Pandas, or Polars. See the jet1090 documentation for [data sources](https://mode-s.org/jet1090/sources/) and [output options](https://mode-s.org/jet1090/output/).
